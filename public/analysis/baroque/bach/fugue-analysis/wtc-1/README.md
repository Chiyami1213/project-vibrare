# Well-Tempered Clavier I: Fugue Analysis

Open `index.html` in a browser. It links all 24 fugue pages (BWV 846–869).

Keep every file in this folder together: the pages load their sound samples from `sounds.js`.

- BWV 846 and 847 were checked by hand (notes compared with a second edition; analysis written by hand).
- BWV 848–869 are an automatic first reading: entries, answers, countersubjects, cadences and sequences were found by a program; Busoni's tempos and marks were read from his edition by hand, entry by entry: each page has a table of what he prints on every entry of the subject, and his countersubject marks are on the score. Each page says what is automatic.
- Notes: David Huron's Humdrum encoding of the Bach-Gesellschaft edition (BG 14). Scores engraved with Verovio.
- Playback: recorded samples, Steinway Grand by default or an Italian harpsichord at A = 415.
