Harpsichord samples
===================

Source: Versilian Community Sample Library (VCSL), "Harpsichord, Italian" (Sustains, stop 1)
https://github.com/sgossner/VCSL
Licence: CC0 1.0 Universal (public domain dedication). No attribution is required; it is given here as a courtesy.

Processing for this site: the 32 sustain recordings were trimmed to 4.6 seconds with a short fade, converted to
mono MP3 (56 kbps), and the sounding pitch of each was measured so every note can be played exactly in tune.
(The recordings sound one octave above their file labels.) manifest.json lists each file and its measured pitch.
